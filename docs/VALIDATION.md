# Validation and known limits

## Scope and provenance

The original repository had only its title README and initial commit. Home Assistant JavaScript, standalone HTML, a checksum list, an earlier implementation plan, and visual clock references were subsequently supplied and inspected. The JavaScript checksum matches. A separate disposable Home Assistant 2026.10.2 instance was subsequently created for acceptance; the user’s own instance was not accessed. All screenshots use fictional people and simulated states. No existing Home Assistant file, entity, dashboard, helper, automation, integration, or standalone clock was modified.

## Local evidence

- Production bundle built with esbuild targeting both ES2018 and Safari 12. The bundle is parsed as an ES2018 script and contains no runtime imports.
- Engine tests cover coincident hands, deterministic offsets, direct person/device tracker/sensor states, attributes, aliases, zones, travelling, overrides, unknown states, independence, import validation, privacy exports, seasonal/time/weather selection and finite bounds.
- Chromium tests cover all three themes, editor changes and people CRUD, responsive sizing, reduced motion, text escaping, production bundle registration, rapid state updates, theme switching, keyboard location editing, fullscreen fallback, and the native selector event/property contract.
- Screenshots are generated by browser tests, not mockups. Review the three PNG files alongside the source.
- npm audit found zero reported vulnerabilities after updating Vite to 6.4.4. This is a dependency audit result, not an application security certification.
- HACS root-bundle and filename conventions were checked against the official `hacs/documentation` repository at commit `4f06a5bd11088a21a453fdcb3eda1603353e6c8a`. The online HACS validator has not run here.

Final local run: **25 engine/packaging tests passed; 17 Chromium browser tests passed**, with no skips in those runs. Production build and clean-lockfile installation succeeded; repeat builds produced the same bundle. One attempted WebKit check failed at browser launch because its executable was unavailable, before any card assertions could run. CI workflows are provided but have not executed remotely.

Installed system Chromium is usable; downloaded WebKit is not currently available.
- A real isolated Home Assistant 2026.10.2 instance verified dashboard save/reload, live state changes and native selector registration with zero frontend exceptions. HACS 2.0.5 was installed and its setup form loaded, but authenticated GitHub repository install/update still needs GitHub authorization. The user’s own Home Assistant instance remains untouched.
- Git read and dry-run push work through platform authentication. Direct GitHub API requests currently return a proxy CONNECT denial. The required api.github.com domain was saved in the environment draft; saving does not apply runtime policy. GitHub Actions provides a separate workflow-token route for release publication. No credential values were printed or committed.

## Product limits

- Portraits use existing image URLs or Home Assistant local paths. No direct upload API, authenticated media-source resolver, or native media browser is claimed.
- The clock is fullscreen-capable within a dashboard; no dedicated Home Assistant panel is installed.
- Names can still become crowded with many people at one location. Practical input guards limit a clock to 250 people/locations; no claim of unlimited readability or measured performance at that upper bound is made.
- Automatic seasons are calendar based, and sun/weather entities are optional. Background changes are visual only.
- Presets are stored in this browser on explicit user action; JSON export is the portable backup. No cross-device preset synchronization is included.
- The three themes share the SVG engine and use original vector illustrations rather than photo-realistic clock artwork. Source-defined hand geometry, colors, and layouts are now verified; pixel-perfect alignment against the actual installed image still needs live acceptance. The provided flattened image remains unchanged. A generated transparent derivative and sixteen scene tiles are now included; see ARTWORK.md for fidelity and resolution limits.
- The editor’s guided mode walks the same configuration sections. Home Assistant’s own Save action persists the result; the card does not silently edit dashboards.
